## 主な機能

- **魔獣図鑑トラッカー**:
  - チャットログの捕獲成功メッセージから自動記録
  - 捕獲済み魔獣の非表示、エリア順・レベル順ソート
  - 各魔獣の属性、連携シンボル、固有アクション、および「はなつ」技情報の表示
- **自動ナビゲーション**:
  - ジョブクエスト受注NPCや野外の魔獣生息地、闘獣塔入口への自動移動（vnavmesh / Lifestream 連携）
- **自動戦闘 (ACR)**:
  - 基本コンボ（砕き割り → 噛み砕き → 裂盾斧）と「とらえる」の自動実行
  - 獣心技連携（ビーストハート / ビーストソウル）
  - 鼓舞・声援の自動実行、万象流転（物理・魔法）
  - 魔獣の「はなつ」「最後の一撃」リキャスト制御
  - 蘇生保護機能（蘇生後3秒間の誤爆防止安全待機）
  - オーバーレイの三段階折りたたみ & 3列モード表示
- **スキルシーケンス & ルールモード**:
  - カウントダウン連動の開幕バフ・スキル回し自動実行
  - 闘獣塔向けの条件付きスキル自動制御（ひきつけろ / ちょうはつ等）

## インストール方法（Dalamud）

ゲーム内チャットで `/xlsettings` を開き、「実験的機能」タブの「カスタムプラグインリポジトリ」に以下の URL を追加してください：

```text
https://raw.githubusercontent.com/BOCXIV/Beastmaster-JP/main/repo.json
```

追加後、ゲーム内チャットで `/xlplugins` を開き、プラグイン一覧から **「Beastmaster」** をインストールして有効化（ON）してください。

---

## 主なコマンド

| コマンド | 説明 |
| :--- | :--- |
| `/魔獣使い` または `/beastmaster` | メイン設定ウィンドウ（クエスト・図鑑・装備・ACR設定）を開きます |
| `/魔獣使い 出力` または `/beastmaster output` | 自動戦闘（ACR）の動作 / 一時停止を切り替えます |

---

## 連携推奨プラグイン

本プラグインの自動ナビゲーションやエリア間移動機能を利用する場合、Dalamud 内で以下のプラグインをあらかじめ導入しておくことをおすすめします：

- **`vnavmesh`**: 自動歩行・飛行・障害物回避ナビゲーションに必須
- **`Lifestream`**: テレポートや都市間・エーテライトの自動移動に必須
