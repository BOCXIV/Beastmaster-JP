# 更新履歴 (CHANGELOG)

## 0.1.29.1 (日本語版)

### FF14公式用語への完全準拠
- **盤面名称**: ゲーム内公式表記に従い、「第一盤」「第二盤」「第三盤」「特一盤」「特二盤」に統一（高段表記を撤廃）。
- **コンテンツ・タブ名称**: 「奇盤編成」を公式用語「パーティ編成」に統一。
- **敵モンスター名称**: 全ての敵の「奇子」接尾辞を公式名称「〇〇・ピース」（キャバリアー・ピース、ビショップ・ピース、ユミール・ピース、タナトス・ピース等）に全面置換。
- **ボス名称**: 「貪食のガトラー」「魅惑のパドスール」等の公式名称に統一。
- **ジョブクエスト名**: Lumina 公式データに基づき、「初めての相棒」「魔獣と心通わせて」「ルー派の使役術」「盤上の戦い、闘獣練」「姉弟子と勉強ゴブ！」「同門対決、第二盤」「人と獣が結ぶ絆」「猛者の試練、特一盤」「盤上の王者、特二盤」「極めるは獣の道」に完全準拠。
- **アチーブメントグループ名**: 「ビーストマニア」「盤面制覇」「特盤制覇」「盤面完全制覇」「特盤完全制覇」「盤面勝利評価」「特盤勝利評価」「闘獣練総合」「ビーストトレーナー」「種族統覇」に刷新。

## 0.1.29.0 (日本語版)

### 奇盤編成（ペットパーティ編成）

- 闘獣練タブ内に「奇盤編成」を追加し、編成画面（XBMPetParty）専用のオーバーレイ表示に対応。
- プリセットのスロット数は 10 / 12 / 14 / 15 に対応。盤面やマップに依存せず自由に管理可能。
- プリセットの新規作成、複製、削除、名称変更、共有コード（`BSTPARTY|1`）のインポート・エクスポートに対応。
- 魔獣ドロップダウンに「図鑑番号 - 魔獣名 - 獣レベル」を表示。空きスロットは末尾のみ許容し、重複編成を禁止。
- 「編成を適用」ボタンにより、現在のパーティをクリアした上で、プリセットの順番通りに魔獣を自動加入。

### 闘獣アチーブメント

- 闘獣練タブ内に「闘獣アチーブメント」を追加し、魔獣使い関連の全44アチーブメントを11グループに分類して一覧表示。
- Lumina の Achievement シートから名称、説明、アチーブメントポイント、報酬称号を動的取得（多言語対応）。
- FFXIVClientStructs の Achievement インスタンスから達成状況を安全に取得。
- 「現在のキャラクターの達成状況を同期」ボタンにより、キャラクター別にアチーブメント進捗を保存。

### 闘獣攻略ガイド

- 闘獣練タブ内に「闘獣攻略」を追加し、第一盤 / 第二盤 / 第三盤 / 高段第一盤 / 高段第二盤の各攻略タブを提供。
- 第三盤の全8層の攻略データ（ボス出現位置、出現敵、ギミック解説、攻略のコツ）を完全日本語で収録。

### ビーストランクと経験値

- 闘獣練のリザルト画面（XBMResult）から、参戦した最大10体のペットの育成データ（ビーストランク・経験値）を自動取得し、キャラクター別に保存。
- NPC「ローダ」で魔獣図鑑（XBMMonsterNotebook）を開いて魔獣を選択した際、単体の育成データを自動同期。
- 「育成データを一括同期」ボタンを追加。図鑑を自動ページめくり・選択走査し、全50体の育成データを一括取得。
- 魔獣図鑑のレベル表示を「捕獲Lv」「獣Lv」「経験値」の3列表示に刷新。未同期は `--`、Lv25満了は `--/--` と表示。
- 図鑑ソートに「獣レベル順」「獣レベル降順」を追加。

### 自動戦闘 (ACR) の刷新

- 通常ACRを「GCDスキル優先 ＋ 能力技挟み込み（oGCD）」構造に全面刷新。
  - GCDスキル（スマッシュ等の基本コンボ、万象流転、連携技WS）をGCD回転可能時に優先実行。
  - 能力技（はなつ、最後の一撃、きあい、おうえん、安全シールド、呼び笛、とらえる等）をGCDクールダウン中に挟み込み（1つのGCDあたり最大2個、硬直なし時）。
- 新アクション「かりる」（44895）および「魔獣技」（44886）の独立トグルを追加（デフォルト無効）。
- 「きあい」（44905）の実行条件を「御獣の心（獣心[主]）が0、または御獣の心が3かつ技力が0の時」に最適化。
- 「おうえん」（44904）の実行条件を「獣霊の心（獣心[従]）が0、または獣霊の心が3かつ獣力が0の時」に最適化。
- FF14公式用語に徹底準拠（「きあい」「おうえん」「かりる」、基本コンボ「スマッシュ」「アクスバイト」「シールドスプリッター」、属性アクス「アバランチアクス」「ミストラルアクス」「スピニングアクス」「ラファールアクス」、万象流転「ブルータルレイジ」「ホークスパイク」「ライジングフォール」「カラミティ」、かりる派生「ビーストスキン」「ヴァイルスキン」「クラウドスキム」「シードサワー」「クェリングウェーブ」「スケイルスキン」「ソウルクラッシュ」「アッシュクレンズ」）。

### ルールモードとクルーシブルアイテム

- ターゲットDataID判定条件を追加。
- クルーシブルアイテム（回復薬・各種牙）の自動投擲アクションに対応。
- デフォルトルールセットに「最終バースト-1層」（対象DataID: 19344、各種牙を使用、エリア1339〜1343限定）を追加。
- 回復薬は 3級 → 2級 → 1級 の優先度で自身に使用。各種牙は 風之牙 → 雷之牙 → 氷之牙 → 火之牙 の順に利用可能なアイテムを自動選択してターゲットに使用。

### 自作カウントダウン機能

- チャットコマンド `/魔獣使い カウントダウン [秒数]`（デフォルト10秒）でカスタムカウントダウンを開始可能。
- `/魔獣使い カウントダウン キャンセル` で中止可能。
- スキルシーケンスサービスと連携し、指定秒数後に開幕スキル回しをスムーズにトリガー。

## 0.1.25.0

### 自動戦闘 (ACR)

- 新機能「低HP時に自動で魔獣回復薬を使用」を追加（デフォルト無効、デフォルト閾値30%）。闘獣練（エリア 1339〜1343）の戦闘中のみ発動し、3級 → 2級 → 1級の優先度で自動使用。
- 魔獣回復薬はクライアントネイティブのホットバースロット実行経路を採用：Agent 497（XBMContentsMainHUD）のマッピング更新、InstanceContentDirector の在庫と使用可否を検証し、RaptureHotbarModule.ExecuteSlot で自身へ実行。
- 新機能「安全シールド」を追加：ターゲットとの距離が 3 yalms 以内で、シールドチャージ（44893）が使用可能な場合に自動使用。リクエスト成功後に独立した2秒のクールダウンを設け、連続送信を防止。
- 設定保存失敗時の保護：ファイル書き込み権限不足などによる例外を捕捉し、5秒ごとに節流してエラーログを記録。例外によるUIクラッシュを防止。
- 連携技2段目のログ改善：状態コード・待機残り時間・完了エッジのログを詳細化し、待機中に連携技1段目を多重起動しないようガードを追加。
