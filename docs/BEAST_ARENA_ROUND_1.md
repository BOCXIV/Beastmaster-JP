## 保守ルール

1. 「アイテム使用禁止：闘獣練」によって一局の開始を特定し、最後の「戦闘終了」によって終了を特定すること。
2. ログファイルに複数局が含まれる場合は、時刻または行番号で分割してから比較し、ファイル全体をそのまま差分比較しないこと。
3. ターゲット可能な非 `9020` エンティティを Boss 本体とみなすこと（`9020` は通常、同名のターゲット不可ギミックエンティティ）。
4. 同名スキルに複数の Action ID が存在する場合はすべて保持し、Boss 本体の開始詠唱 ID のみで切り捨てないこと。
5. 新しい Boss は対戦ごとにブランチを作成し（例：「第2戦 分岐 C」）、既存のランダム分岐を上書きしないこと。
6. ログに実際に記録されたデータのみを記述し、名称が空の場合は「未記録」と表記すること。
