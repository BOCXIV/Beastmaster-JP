# 魔獣レベルと経験値 取得設計書

## 目的

ゲーム UI またはクライアントメモリから、捕獲済み魔獣ごとの育成データを取得し、プラグインの魔獣図鑑に表示します：

- 現在の獣レベル（ビーストランク）
- 現在の経験値
- 次のレベルまでの必要経験値

図鑑の既存の「レベル」フィールドはモンスター本来の捕獲地点レベルであり、ペット自身の育成レベルとは異なります。そのため、「捕獲Lv」と「獣Lv」「経験値」を明確に分離して表示します。

## データ取得経路

### 1. 闘獣練リザルト画面（`XBMResult`）
闘獣練の各回終了時に表示される `XBMResult` リザルト画面から、参戦した最大10体のペットの育成データを直接取得します：
- アイコン：`AtkValue 73..82`（図鑑番号 = IconId - 242000）
- リザルト前経験値：`89..98`
- リザルト後経験値：`105..114`
- リザルト前獣レベル：`121..130`
- リザルト後獣レベル：`137..146`

リザルト画面が表示されている間、250msごとに読み取りを行い、データが連続して安定した段階でキャラクター別に保存します。日常のレベリングにおいて、手動で編成画面を開く必要がありません。

### 2. NPC「ローダ」の魔獣図鑑（`XBMMonsterNotebook`）
NPC「ローダ」に話しかけて魔獣図鑑を開いた際、選択中の魔獣の詳細フィールドから単体のデータを取得します：
- `Value[229]`：表示番号
- `Value[231]`：アイコン
- `Value[258]`：獣レベル
- `Value[261]`：現在の経験値
- `Value[262]`：経験値上限

表示番号とアイコンの一致を検証した上で、安全にキャッシュを更新します。

### 3. 一括同期サービス（`BeastmasterNotebookSyncService`）
魔獣図鑑を開いた状態で「育成データを一括同期」ボタンをクリックすると、図鑑選択プロトコル（Agent 500 `ReceiveEvent` eventKind=0）を利用して自動でページ切り替えと魔獣の選択走査を行い、全50体の育成データを一括で取得・保存します。

## 図鑑表示とソート

- 図鑑テーブルに「捕獲Lv」「獣Lv」「経験値」の3列を表示。
- 未同期の魔獣は `--`、Lv25満了魔獣は `--/--` と表示。
- 「捕獲レベル順ソート」と「獣レベル順ソート（昇順/降順）」に対応。未同期の魔獣は末尾に配置。
