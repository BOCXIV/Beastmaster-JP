# BOSS 規則とクルーシブルアイテム検証記録

## ステータス

タスクは完了し、ゲーム内での検証を完了した上で `0.1.26.0` 以降に正式リリースされました。

## 検証済み項目

- `TargetStatus` の BUFF 存在および欠落条件が正しく一致し、スキルが実行されることを確認。
- `DataIdStatus` の BUFF 存在および欠落条件がシーン内のオブジェクトを正しく検索し、スキルを実行することを確認。
- `TargetDataId` が現在のターゲットの `BaseId` に基づいてルールと一致することを確認。
- クルーシブルアイテム規則で「魔獣回復薬」を選択した際、3級 `78` → 2級 `77` → 1級 `76` の優先度で自身に使用されることを確認。
- クルーシブルアイテム規則で「各種牙」を選択した際、現在のターゲットに対して利用可能な牙を自動選択して使用することを確認。
- 確認済みの牙アイテム：火の牙 `128`、氷の牙 `129`、水の牙 `130`、雷の牙 `131`、土の牙 `132`、風の牙 `133`、吸血鬼の牙 `134`。
- クルーシブルアイテム規則で回避の書 `137`、反射の書 `136`、時の砂 `138`、魔獣剛力薬 `104`（自身対象）、吸血鬼の牙 `134`（敵対象）の実行に対応。
- 1ルールあたり最大10個の条件を設定可能な複数条件（すべて満たす AND / いずれかを満たす OR）に対応。
- 自身HPおよびターゲットHP条件（> または <）、ターゲットがBOSS（IsBoss）条件に対応。
- ルール命中時に実行失敗した際、後続ルールへフォールバックするよう改善。
- クルーシブルアイテムは Agent 497 のスロットマッピング、InstanceContentDirector の在庫検証、および `RaptureHotbarModule.ExecuteSlot` を通じて実行されることを確認。
- ターゲットアイテム使用時は SoftTarget を一時的に現在のターゲットに設定し、回復薬使用時は自身に設定、実行後に元の SoftTarget へ復帰することを確認。
- クルーシブルアイテムの DEBUG リストは ID 重複排除を行い、`76〜143` 以外の疑似エントリをフィルタリングすることを確認。
- ルール診断（詳細レベル）でアクション成功ログが出力され、同一の失敗原因によるチャットの連続スパムを防止することを確認。

## デフォルトルール

デフォルトルールセットは闘獣練エリア（TerritoryType `1339〜1343`）でのみ有効であり、以下のルールがデフォルトで有効化されています：

```text
[ルール]
名称|最終バースト-1層
有効|True
判定|TargetDataId
実行|CrucibleItem
クルーシブルアイテム種別|Fang
DataId|19344
```

## スコープ決定事項

以下の機能は検討の結果、非実装となりました：

- 「通知のみ / 手動実行 / 自動実行」の3モード切り替え。
- 独立した「ターゲットHP閾値 ＋ 指定呼び笛番号」の最終バースト機能。

既存の「最終バースト-1層」はターゲット DataID 一致時に各種牙を使用するデフォルトルールであり、上記の非実装機能とは異なります。
