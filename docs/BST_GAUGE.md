# 魔獣使い ジョブHUD（量譜）資料

本文書は、魔獣使いのジョブHUDおよびゲーム内データ仕様をまとめた資料です。

## ジョブHUD（量譜）フィールド

プラグインは `JobGaugeManager.Instance()->CurrentGauge` から 48 バイトを読み取り、以下のフィールドを使用します：

| オフセット | 表示名称 | 説明 |
| --- | --- | --- |
| `+0x10` | 技力 (TP) | プレイヤー自身のTP、上限は 250 |
| `+0x11` | 獣力 (BeastPower) | ペットのTP、上限は 250 |
| `+0x13` | 現在の呼び笛 | `1〜3` がそれぞれ一号、二号、三号呼び笛に対応。0は未召喚 |
| `+0x18` 上位 | 御獣の心（獣心[主]） | 生値の右シフト 2ビット：`raw >> 2` |
| `+0x18` 下位 | 獣霊の心（獣心[従]） | 生値の下位 2ビット：`raw & 3` |

また、プレイヤー自身のステータスリストから以下の連携ステータスを取得します：

- `4599`：活命撃（光）
- `4600`：滅命撃（闇）

これらはプレイヤーのステータス情報であり、`CurrentGauge` のメモリバイトではありません。

## 獣心技連携

- 獣心技には 翔、猛、堅、魔 の 4 属性が存在します。
- 獣心技の発動時、連携シンボル上に該当属性が点灯します。
- 魔獣使いまたはペットの一方が獣心技を発動後、7秒以内にもう一方が発動することで「獣心技連携」が発生します。
- 時計回りの属性順（翔→猛→堅→魔→翔）で繋ぐことで、より強力な「獣心技連携II（活命撃 / 滅命撃）」が発生します。
- 活命撃または滅命撃の状態で「きあい」等を用いて連携を繋ぐことで、最上位の「獣心技連携III・万象流転」へと発展します。
