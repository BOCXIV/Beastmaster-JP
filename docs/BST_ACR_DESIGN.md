# 魔獣使い ACR 設計説明

## 目的

魔獣使い ACR（`Beastmaster ACR`）は、プレイヤーが明示的に自動戦闘を有効化した際、現在手動で選択しているターゲットを中心に基本コンボや捕獲（とらえる）フローを実行し、高度アクションに対して安全かつ制御可能なリソース判定とトグルを提供する機能です。

設計原則：

- デフォルトでは自動戦闘は無効。
- デフォルトでは高度アクションの自動実行は無効。
- プレイヤーが現在手動で選択しているターゲットに対してのみアクションを実行。
- 捕獲状態の判定には `StatusId` および `SourceId` の完全一致を必須とする。
- ジョブHUD（量譜）やランタイム状態の取得は完全読み取り専用とし、ゲームメモリへの書き込みは一切行わない。
- 重要ステータスが確認できない場合は高度アクションを停止し、理由を表示する。

---

## 実装済み機能

### 闘獣練ナビゲーション

ツールリストに「闘獣練へ移動」項目を提供。クリックで既存の飛行ナビゲーションおよびエリア間移動を活用し、目標である `TerritoryType=148`、`Map.RowId=4`、黒衣森：中央森林ワールド座標 `X=24.238, Y=-6.003, Z=65.809` へ移動します。

自動戦闘設定にデフォルト無効の「オーバーレイ3列モード」を提供。有効化するとオーバーレイの高度アクションボタンが3列で配置されます（1行目：獣心連携、獣霊連携、きあい；2行目：万象・物理、万象・魔法、おうえん；3行目：自動呼び笛、最後の一撃、はなつ；4行目：継続ひきつけ、継続ちょうはつ、安全シールド）。無効時は従来の2列レイアウトとなります。

### 安全シールド（シールドチャージ）

安全シールドはシールドチャージ（44893）を使用する機能で、デフォルト無効です。プレイヤーから現在のターゲットまでの距離が 3 yalms 以内で、かつアクション状態が使用可能な場合にのみ自動使用します。リクエスト成功後は 2 秒間の独立クールダウンに入り、連続誤送信を防止します。

### 魔獣回復薬（闘獣練専用）

「低HP時に自動で魔獣回復薬を使用」はデフォルト無効、HP閾値のデフォルトは 30%（1%〜100% 設定可能）です。自動戦闘が有効かつ非一時停止、プレイヤーが魔獣使い、闘獣練（TerritoryType 1339〜1343）の戦闘中で、自身HPが閾値未満のときのみ実行されます。専用回復薬は 3級（78）→ 2級（77）→ 1級（76）の優先度で自動使用されます。
優先順位：スキルシーケンス → 魔獣回復薬 → ルールモード → 連携技2段目 → はなつ → 最後の一撃 → きあい → おうえん → 万象流転 → 連携技1段目 → 安全シールド → とらえる → 基本コンボ。

### 基本自動戦闘

基本コンボ順序：

```text
スマッシュ (44879) → アクスバイト (44883) → シールドスプリッター (44885)
```

実行前チェック：

- 自動戦闘が有効であること。
- プレイヤーが魔獣使いであること。
- プレイヤーが存在・生存しており、詠唱中でないこと。
- エリア切り替え、マウント搭乗、カットシーン中でないこと。
- キャラクターのHPが0から復帰後3秒間は蘇生保護状態となり、この間はスキルシーケンス、ルールモード、自動呼び笛、通常ACRのいずれもアクションを実行しない。
- 現在のターゲットが選択可能な BattleNpc であること。
- ターゲットが存在・生存しており、HPが0より大きいこと。
- `ActionManager` が使用可能であり、対象スキルの実行が許可されていること。

### 捕獲（とらえる）フロー

捕獲トグルが有効な場合：

```text
ターゲットのHP < 捕獲閾値
かつターゲットに自身が付与した捕獲ステータスがない
→ 「とらえる」を実行
```

ターゲットのHPが閾値以上の場合は基本コンボを継続します。捕獲閾値の範囲は `1%〜100%`、デフォルトは `80%` で、メイン画面およびオーバーレイで変更可能です。

捕獲ステータスの判定：

```text
status.StatusId == 捕獲ステータス
かつ status.SourceId == LocalPlayer.EntityId
→ 自身の捕獲ステータスとして判定
```

他プレイヤーが付与した同名ステータスは自身の判定を阻害しません。

捕獲リクエスト送信後は短い待機ウィンドウに入り、自身の `SourceId` ステータス更新を待ちます。待機中は重複リクエストを行わず、ターゲットへのダメージ攻撃も停止します。ターゲット切り替え、ターゲット喪失、または自動戦闘オフ時に捕獲状態をリセットします。

### ジョブHUD（量譜）読み取り

以下のアドレスから 48 バイトを安全に読み取り：

```text
JobGaugeManager.Instance()->CurrentGauge
```

フィールド：

| フィールド | オフセット | 上限・分割 |
| --- | --- | --- |
| 技力 (TP) | `+0x10` | `250` |
| 獣力 (BeastPower) | `+0x11` | `250` |
| 現在の呼び笛 | `+0x13` | `1〜3` が各呼び笛に対応 |
| 御獣の心（獣心[主]） | `+0x18` | `raw >> 2` |
| 獣霊の心（獣心[従]） | `+0x18` | `raw & 3` |

サンプリング周期は 100ms で、UI はキャッシュされたスナップショットを使用します。

## ルールモードとクルーシブルアイテム

闘獣練エリア（`1339〜1343`）専用のルールセットを提供します。デフォルトで「最終バースト-1層」ルールが有効です。

ルール条件：
- 自身 / ターゲット BUFF
- DataID BUFF
- DataID 詠唱
- ターゲット詠唱
- ターゲット DataID（ターゲットの `BaseId` のみ比較）

ルールアクション実行種別：
- スキル実行
- クルーシブルアイテム使用：
  - 回復薬：3級 `78` → 2級 `77` → 1級 `76` の優先度で自身に使用。
  - 各種牙：風之牙 `133` → 雷之牙 `131` → 氷之牙 `129` → 火之牙 `128` の順に利用可能なアイテムを自動選択し、ターゲットに使用。

アイテム使用時は Agent 497（XBMContentsMainHUD）のスロットマッピング、InstanceContentDirector の在庫検証、および `RaptureHotbarModule.ExecuteSlot` を経由して実行します。

## ビーストランクと経験値

闘獣練のリザルト画面（`XBMResult`）から、参戦した最大10体のペットの育成データを自動読み取りします。
- アイコン：`AtkValue 73..82`（図鑑番号 = IconId - 242000）
- リザルト前経験値：`89..98`
- リザルト後経験値：`105..114`
- リザルト前獣レベル：`121..130`
- リザルト後獣レベル：`137..146`

リザルト画面が表示されている間、250msごとに読み取りを行い、データが連続して安定した段階でキャラクター別に保存します。

また、NPC「ローダ」で魔獣図鑑（`XBMMonsterNotebook`）を開いた際にも、選択中の魔獣の詳細（表示番号、アイコン、獣レベル、経験値、上限）を自動同期可能です。図鑑の一括同期ボタンにより、全50体の魔獣データを自動走査して更新することもできます。

## 奇盤編成（ペットパーティ編成）

「闘獣練」タブ内に「奇盤編成」を提供し、ゲーム内の編成画面（`XBMPetParty`）と連携する専用オーバーレイを表示します。
- スロット数：`10 / 12 / 14 / 15` に対応。
- プリセットの新規作成、複製、削除、名称変更、共有コード（`BSTPARTY|1`）のインポート・エクスポートに対応。
- 「編成を適用」ボタンをクリックすることで、現在の編成をクリアし、プリセットの順番通りに魔獣を自動登録します。

## 自作カウントダウン機能

ゲーム標準のカウントダウンに加え、チャットコマンド `/魔獣使い カウントダウン [秒数]`（デフォルト10秒）でカスタムカウントダウンを開始できます。
スキルシーケンスサービスと連動し、開幕のスキル回しをスムーズにトリガーします。キャンセルは `/魔獣使い カウントダウン キャンセル` で行えます。

## スキル優先順位と判断構造

通常の自動戦闘は「GCDスキル優先 ＋ 能力技挟み込み（oGCD）」の構造を採用しています。

### スキル分類

| 種別 | アクション |
| --- | --- |
| GCD | 基本コンボ（スマッシュ `44879` → アクスバイト `44883` → シールドスプリッター `44885`）、万象流転（ブルータルレイジ等）、獣心技連携WS |
| 能力技 (oGCD) | はなつ、最後の一撃、きあい、おうえん、安全シールド、呼び笛 1/2/3、とらえる、おおわざ、かりる、魔獣技 |

### 判定順序

```text
自動戦闘スイッチ & 一時停止状態チェック
→ キャラクター状態チェック（蘇生保護など）
→ スキルシーケンス実行
→ 戦闘中のルールモード
→ 低HP時の自動魔獣回復薬
→ 現在のターゲット確認
→ 捕獲待機保護
→ アニメーションロック確認（AnimationLock > 0 の場合は待機）
→ 待機中の連携技2段目
→ ペット不在時の自動呼び笛
→ GCD判定（基本コンボ現在ステップの GetActionStatus == 0）
   ├─ GCD回転可能 → GCDスキル実行：万象流転 → 連携技1段目 → 基本コンボ（成功時oGCDカウントリセット）
   └─ GCDクールダウン中 → 能力技（oGCD）挟み込み（1つのGCDウィンドウ内に最大2回、硬直なし時）：
        とらえる → かりる → 魔獣技 → きあい → おうえん → はなつ → 最後の一撃 → 安全シールド → おおわざ
```

### 能力技挟み込みルール

- 能力技は GCD のリキャスト回転中かつ `AnimationLock == 0` の時のみリクエストされます。
- 1つの GCD ウィンドウにつき最大 2 個の能力技を実行できます。GCD スキルの成功時にカウントがリセットされます。
- 安全シールド（44893）は 2 秒の独立クールダウンを持ち、連続 GCD ウィンドウに自然に分散されます。
- 「かりる」（44895）および「魔獣技」（44886）は独立した設定トグルを持ち、デフォルトは無効です。
- おおわざ（47093）は連携モードが無効の時のみ独立した能力技として自動実行され、連携技との競合を防ぎます。
- 自動呼び笛はペットがいない場合に独立して実行され、挟み込みカウントの制限を受けません。
